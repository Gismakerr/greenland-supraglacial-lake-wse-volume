# Code

按文件名前缀 `01` 到 `13` 顺序执行。每个公开脚本只对应一个同名结果目录，默认是安全检查模式，添加 `--run` 才执行。

`08_fit_area_wse_curves.py` 是面积–水位拟合的唯一公开入口：读取统一观测表，比较一次和二次模型，用 AICc 选择最终模型，并强制 `R² > 0.8`。

`09_summarize_observations.py` 是统计整理的唯一公开入口：从冻结的 S2/SWOT 状态记录生成湖泊、分支和拟合单元三层统计，并核验论文锁定总数。

`10_estimate_lake_volume.py` 是水量变化的唯一公开入口：继承第 08 步最终 AICc 模型，计算 83 个拟合单元的面积、水位、相对库容和逐时段变化。

`11_compose_slc_phase_panels.py` 是原第 14 步图件的精简公开入口：只读取本包内12张冻结的 Lake 1 四联图，生成两张6行论文组图，不重新计算相位或改动原始图像内容。

`12_collect_paper_figures.py` 是论文组图总目录的公开入口：刷新第10/11步图件副本，并校验全部6张概念组图、9个实际文件的尺寸和 SHA-256。

`13_prepare_thematic_map_data.py` 是专题地图数据入口：核验一套完整湖泊 Shapefile、498 条湖泊级地图属性、152 条分支级人工分类及图例定义；`--run` 只刷新分类汇总，不访问原始 Z 盘目录。

`_engine` 是前 7 步冻结的原算法实现，`_archive` 是历史快照与审计材料；两者都不是日常入口。
